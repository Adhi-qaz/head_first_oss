# Contributing

1. Fork this repo, then clone your fork.
2. Create a branch: `git checkout -b your-name/short-description`
3. Pick an open issue and comment "working on this" before you start.
4. Make your change. For HTML/CSS/JS, open `index.html` in a browser to check it.
   For Python, run `pytest tests/` and confirm the relevant test goes green.
5. Commit with a clear message and push your branch.
6. Open a pull request against `main`. Fill in the PR template.
7. Address review comments with new commits on the same branch.
